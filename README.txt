English Step 3.0

Веб-приложение для изучения английского с нуля. Словарь: 100 слов и выражений из списка пользователя. Раздел фраз: 300 уникальных учебных фраз, собранных из существующей лексики, с русским переводом и грамматическим объяснением. Режимы: выбор перевода, слух, сборка фразы. Американское произношение через системный синтез речи en-US. Прогресс сохраняется локально в браузере.

Запуск: открой index.html. Для установки на iPhone как веб-приложения размести все файлы на HTTPS-хостинге, затем Safari → Поделиться → На экран Домой.
